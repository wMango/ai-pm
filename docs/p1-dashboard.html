P1 · Dashboard

一条命令，
得到一张离线项目地图

运行 npm run pm -- dashboard，读取 .pm/ 下的三份输入，生成单文件 dashboard.html：五个视图、可交互、不联网、双击即开。

01

真实生成的页面

下面就是用示例项目生成的 dashboard.html，可以直接操作：切换视图、点击模块、跳转。

02

从 .pm/ 到页面

CLI 只做读取与写出；计算全在 P0 引擎里；渲染器负责拼装与转义。

03

页面里的五个视图

从上到下依次展开；任何视图出错只影响它自己。

04

不可信的名字，只会显示成文字

pm.yaml 可能由 AI 或第三方写入。一个恶意名字要经过三道关，最终只会以文字形式出现。
