ai-pm · Platforms

一个 pm，
四个代理平台

核心是同一个命令行工具。Claude Code 与 Codex 直接装插件；OpenCode 与 DeepSeek Harness 用 pm setup 一条命令接入。功能层验收在所有平台上都只能由你在终端里按 y 锁定。

01

能力矩阵

实心为完整支持，半色为部分支持（由 AI 按指令执行），空心为暂不支持。最后一行是我实际验证到的程度。

02

安装与使用

OpenCode 与 DeepSeek Harness 需要先在本机构建一次：git clone … ~/ai-pm && cd ~/ai-pm && npm install && npm run build:plugin。下文 PM = node ~/ai-pm/plugin/bin/pm.mjs。

03

OpenCode 插件做了什么

OpenCode 不能加载 Claude Code 的钩子，pm setup 生成的 JS 插件把它的事件翻译成同样的 pm hook 调用。

04

谁来做：人 · AI · 自动

自动化越完整，你需要操心的越少；但"什么算完成"始终由你在终端里拍板。
