一个 Skill 加三个钩子：开工前起草并锁定验收条目，每轮对话记录 token，会话结束在后台跑验收、刷新地图，新会话开始时把"下一步"交给 AI。

01

一次会话里，谁在什么时候做什么

人只在两处出手：确认目标、确认功能层验收条目。其余由 AI 和钩子完成。

02

SessionEnd 只有 1.5 秒：交给后台

官方限制 SessionEnd 钩子约 1.5 秒且插件无法调高。实测钩子 0.08 秒返回，验收由脱离的后台进程完成。

03

Token 怎么算

以本项目这次真实会话为例：缓存读取是每轮重复读取上下文，计入会淹没其他一切。默认只算"新处理"的部分，明细全部保留。

04

锁定与待复核

锁定记录 sha256 指纹。任何能让"测试变松"的改动都会被标出来，等人复核。

05

审查与加固

独立安全审查发现 2 个 HIGH、8 个 MEDIUM、6 个 LOW。左边是处理情况，右边是新增的"本机信任"闸门：别人改过的测试命令，不会在会话结束时被无人值守地执行。
